Privacy Policy

xPenditur — a personal, self-hosted finance tracker · Last updated: 12 July 2026

1. What this application is

xPenditur is a personal, single-user application. This instance is operated by its sole user for their own private, non-commercial finance tracking. It is not a service offered to the public, it has no registration, and it processes personal data belonging only to its operator. The operator of this instance is therefore both the data controller and the only data subject.

2. Data processed

  • Financial transaction data — amounts, dates, descriptions, counterparties and categories, entered manually by the operator, imported from the operator's own bank statement files, or retrieved from the operator's own bank accounts through the Enable Banking PSD2 interface after the operator's explicit, bank-side authorization.
  • Email data — invoice and receipt emails read (read-only) from mailboxes owned and configured by the operator, for the purpose of extracting transaction details.
  • Technical data — a session cookie used solely for authentication. No analytics, tracking, advertising or profiling of any kind takes place.

3. Where data is stored

All data is stored in a local database on a server controlled by the operator. Credentials (mailbox passwords, API keys, banking application keys) are encrypted at rest. No data is transmitted to third parties, sold, or shared.

4. Third-party processors

  • Enable Banking (enablebanking.com) — used as the PSD2 account-information provider to retrieve the operator's own bank transactions, subject to Enable Banking's own privacy policy. Access is granted per bank by the operator through the bank's own consent flow and can be revoked at any time.
  • DeepSeek (deepseek.com) — receives the text of invoice emails or statement documents, configured by the operator, solely to extract structured transaction data.

5. Retention and deletion

Data is retained until the operator deletes it. As the sole user and controller, the operator can view, modify, export or permanently delete all stored data at any time, directly.

6. Your rights & contact

Since the only personal data processed belongs to the operator of this instance, GDPR data-subject requests do not arise from third parties in normal operation. Any questions regarding this instance and its data handling can be addressed to the operator: pahpahdow@gmail.com.
